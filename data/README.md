# Dataset

## Primary Dataset

File: `datasetfull.csv`

This is the primary dataset used by all members of the GoldSense project.

### Dataset Details

- Data type: Daily Indian gold prices
- Period: 2011–2018
- Columns: Date, Price

### Important Team Rule

All team members must use the same `datasetfull.csv`.

Do not replace it with another gold-price dataset without discussing it with the group.

### Usage

Download `datasetfull.csv` from the original project/source and place it inside the local `data/` folder before running the notebooks.
