# GoldSense Dashboard

The GoldSense Dashboard is an interactive Streamlit-based interface developed to present gold price analysis, machine learning predictions, anomaly detection, and time-series forecasting results in a simple and user-friendly format.

## Features

### 1. Dashboard
- Displays important gold price KPIs.
- Provides a date-range filter.
- Shows historical gold price trends.
- Allows users to select indicators such as:
  - Gold Price
  - 30-Day Moving Average

### 2. EDA & Trends
- Historical gold price analysis
- Monthly average price
- Price distribution
- Daily return analysis
- Dataset preview

### 3. Market Analytics
- Daily returns
- Moving averages
- Volatility
- Momentum
- Price comparison with moving averages

### 4. Anomaly Detection
- Identifies unusual gold price movements.
- Displays the total number of anomalies.
- Shows normal and anomalous observations.
- Provides a visual representation of detected anomalies.

### 5. ML Prediction
The dashboard integrates the trained machine learning models:
- Linear Regression
- Random Forest
- Gradient Boosting

Users can select a model and view the predicted gold price.

### 6. Forecasting
The dashboard provides time-series forecasts using:
- ARIMA
- SARIMA

Forecasted gold prices for the next 30 days are displayed using interactive charts and tables.

### 7. About Project
Provides an overview of the GoldSense project, its workflow, technologies used, and major project components.
