# GoldSense

GoldSense is a gold price analysis and forecasting project using Python, SQL, Machine Learning, and Time-Series Analysis.

## Project Objective

The project analyzes historical Indian gold prices to identify price trends, returns, volatility, unusual price movements, and patterns, and then applies machine learning and time-series forecasting techniques.

## Dataset

Primary dataset: `datasetfull.csv`

- Daily Indian gold prices
- Period: 2011–2018
- Main columns: Date, Price
